## How to Update on GitHub

1. Gå till: https://github.com/skabbio1976/vcenter
2. Klicka på kugghjulet (⚙️) bredvid "About"
3. Klistra in beskrivningen ovan
4. Lägg till topics genom att skriva varje tag och trycka Enter
5. Lägg till website URL (om du vill)
6. Klicka "Save changes"

- Settings → Branches → Add rule
- Require pull request reviews
